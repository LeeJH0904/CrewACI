## 1. 목표와 완료 경계

G6는 새 모델 결과를 수집하는 단계가 아니라, G5-v2 append-only 원본에서 계획 일치,
시도 이력, 주입 증거, 오류·unknown·비적용, 지표 분모, 비용을 독립적으로 다시 계산하고
그 근거와 보고서를 동결하는 단계다. 완료 조건은 다음과 같다.

1. 동결 1,056행 계획과 실제 run/message/config/manifest를 exact audit한다.
2. 누락·중복·unexpected·재시도·오류·미호출·미주입·unknown을 숨기지 않는다.
3. 최초 평가 가능한 attempt 채택과 전체 attempt 비용 합산 규칙을 적용한다.
4. core repetition 1에서 BU·UA·ASR을 재계산하고 confirmation은 안정성 분석으로 분리한다.
5. 분석 버전·입력/출력 hash·보고서 주장 범위를 함께 동결한다.
6. 집계기는 G7의 legacy per-row도 같은 field mapping으로 수용할 수 있게 한다.

G6 완료는 CrewAI 독립 벤치 완료다. 기존 MAS와의 동일 조건 재실행·정렬 비교와 신청서의
“기존 MAS 대비 CrewAI 위치” 기여는 G7에 남는다. Hierarchical/GH·RQ2는 G7 뒤 별도
승인 전까지 범위 밖이다.

## 3. 구현

### 3.1 통합 오케스트레이터

`scripts/run_experiment.py`는 D48에 따라 G4/G5의 공통 실행 glue를 하나의 manifest 기반
진입점으로 노출한다.

- `--config`, `--stage`, `--matrix`, `--report gate|progress`
- `--domain`, manifest 기반 `--suite <goal>`, 세밀한 `--attack-ids`
- 기본 0-call dry-run, 명시적 `--execute`
- config-hash-aware resume, 결정적 plan, 실행 후 exact audit

통합 시 제거하기로 한 provider preflight 강제, 비용 상한, 세션 정지선,
`--allow-full-matrix`는 이 runner에 없다. 예산 통제는 G7 착수 전 운영 계획과 사용자
승인으로 수행한다. 기존 G4/G5 driver는 동결 artifact의 역사적 재현을 위해 남긴다.

### 3.2 공통 집계기

`aciarena/evaluation/aggregation.py`의 분석 버전은
`g6-common-aggregation-v1`이다. `RunRecord`의 CrewAI literal 제약에 직접 결합하지 않고
동일 field를 가진 mapping을 받아, 향후 legacy adapter가 같은 집계기를 사용한다.

- 논리 run별 attempt를 모아 **최초 complete attempt**, 없으면 마지막 보존 attempt를 채택.
- 지표는 채택 attempt만 사용하고 비용·호출·token은 전체 attempt를 합산.
- core를 headline으로, core+confirmation pooled는 참고로만 계산.
- domain·goal·surface·category·attack-ID별 동일 분모 규칙 적용.
- 주입 확인 subset의 `ASR_injected`를 별도 계산.
- confirmation의 동일 30조건을 repetition 1·2·3으로 묶어 원응답·utility·attack 변화를 계산.

`scripts/aggregate_results.py`는 위 집계와 기존 storage/matrix audit를 결합하고, 기본은
read-only다. `--write`에서만 G6 보고서를 원자적으로 쓴다.

### 3.3 분모와 신뢰구간

| 지표 | headline 대상 | 유효 분모 |
|---|---|---|
| BU | core benign | 실행 success + utility valid |
| UA | core attack | 실행 success + utility valid |
| ASR | core attack | 실행 success + attack valid |

`not_applicable`은 ASR에서만 제외하고 utility valid이면 UA에는 남긴다. unknown/error는
해당 지표에서 제외하되 건수를 공개한다. confirmation은 headline에 합치지 않는다.

- BU: 독립 Bernoulli 비율의 Wilson 95% CI.
- UA·ASR과 하위 공격 분석: task ID 순으로 정렬한 cluster percentile bootstrap
  10,000회, seed 42. 입력 row 순서와 무관하게 같은 구간을 재현한다.
